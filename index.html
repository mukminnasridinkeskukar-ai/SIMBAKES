Petunjuk Penggunaan

Panduan lengkap penggunaan platform SIMBAKES

1 Memulai Pengajuan Beasiswa

Untuk memulai pengajuan beasiswa tematik bidang kesehatan, ikuti langkah-langkah berikut:

  1. Akses menu Layanan → Formulir Usulan Rekomendasi
  2. Isi formulir pengajuan dengan data yang lengkap dan benar
  3. Unggah dokumen pendukung yang diperlukan (KTP, ijazah, surat rekomendasi, dll)
  4. Periksa kembali semua data sebelum mengirimkan
  5. Klik tombol "Kirim Usulan" untuk submit pengajuan

2 Mengecek Status Pengusulan

Setelah mengirimkan usulan, Anda dapat memantau statusnya kapan saja:

  1. Buka menu Layanan → Cek Status Pengusulan
  2. Masukkan Nomor Usulan yang Anda terima saat submit
  3. Klik tombol "Cari" atau tekan Enter
  4. Status dan informasi detail usulan akan ditampilkan

Status Pengusulan:

  • Draft - Usulan belum dikirim
  • Dalam Review - Sedang diverifikasi admin
  • Disetujui - Lolos verifikasi, menunggu penetapan
  • Ditolak - Tidak memenuhi persyaratan

3 Mengecek Status Penetapan

Setelah proses penetapan, penerima beasiswa dapat dicek melalui:

  1. Akses menu Layanan → Cek Status Penetapan
  2. Masukkan NIK atau Nomor Pendaftar
  3. Lihat hasil penetapan dan status beasiswa
