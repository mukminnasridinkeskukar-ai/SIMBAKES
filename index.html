Tentang SIMBAKES

SIMBAKES adalah sistem informasi beasiswa tematik bidang kesehatan yang dikelola oleh Kementerian Kesehatan RI. Program ini bertujuan untuk meningkatkan kualitas sumber daya manusia kesehatan Indonesia melalui pendidikan yang berkualitas.

Sasaran Penerima

  • Tenaga kesehatan PNS/PPPK
  • Dokter/dokter spesialis daerah tertinggal
  • Perawat dan bidan terpilih

Petunjuk Penggunaan Platform SIMBAKES

Panduan lengkap menggunakan fitur-fitur yang tersedia

1

Konfigurasi Database

Klik tombol ⚙️ Settings di header, lalu masukkan URL dan Anon Key dari project Supabase Anda. Jika belum punya, gunakan mode demo dengan data contoh.

2

Melihat Roadmap Kebutuhan

Klik menu "Roadmap Kebutuhan" untuk melihat daftar program beasiswa yang tersedia di database Supabase.

3

Mengajukan Beasiswa

Klik menu "Formulir Pengusulan" untuk mengisi data. Data akan tersimpan langsung ke tabel data_pengusulan di Supabase.

4

Admin Login

Klik "Login Admin" untuk mengakses fitur CRUD lengkap. Admin dapat melihat data sensitif (NIK), mengedit status, dan mengelola user.
